## Best way to use it
This deck is written for **Marp** in VS Code.

### In VS Code
1. Install the **Marp for VS Code** extension if you do not already have it.
2. Open `lidar_project_showcase.md`.
3. Open the Marp preview.
4. Export to PDF, HTML, or PowerPoint if desired.
